# Stavitelé mostu

Výuková aplikace pro 4. ročník: **písemné násobení a dělení do 10 000**.

Žák staví most pro městečko Rovinka. Každá splněná mise přidá kus mostu:

1. Zaměření terénu: dělení se zbytkem zpaměti
2. Materiál na pilíře: písemné násobení pod sebou
3. Rozpočet stavby: odhad, slovní úlohy, pořadí početních výkonů
4. Rozdělení trámů: písemné dělení krok za krokem se zkouškou
5. Kontrola statika: zbytek, zkouška se zbytkem, hledání chyb
6. Kolaudace mostu: závěrečný mix a diplom

## Úprava obsahu

Všechny úlohy jsou v souboru `index.html` v bloku `const HRA = {...}` na začátku skriptu. Engine pod ním není potřeba měnit.
